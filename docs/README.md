# Documentation

This directory contains public documentation for MIDI Command Studio, a Windows application for mapping MIDI hardware to shortcuts, macros, volume controls, soundboard actions, and app-focused workflows.

The application is closed-source. These pages document usage, release information, support routes, screenshots, demos, and verified external resources.
