# Free Vs Full

This page documents the public differences between the free version and the full version of MIDI Command Studio.

## Quick Links

- [README](../README.md)
- [Getting Started](getting-started.md)
- [FAQ](faq.md)
- [Download](https://crowtherian.gumroad.com/l/ddscqt)

## Summary

- Product model: free to try, paid/full version available
- Version documented: `1.2.0`
- Platform: Windows only
- Repository scope: documentation, releases, screenshots, and issue tracking
- Application source code: closed-source / not open source

## Comparison Table

| Feature | Free | Full |
| --- | --- | --- |
| Shortcut mapping for knobs, faders, and buttons | Yes | Yes |
| Macro mapping for knobs, faders, and buttons | Yes | Yes |
| App or system volume mapping | Yes | Yes |
| Per-device presets and quick switching | Yes | Yes |
| App targeting | Yes | Yes |
| LED feedback | Yes | Yes |
| MIDI Thru | Yes, requires a virtual MIDI port | Yes, requires a virtual MIDI port |
| Mackie / MCU support | Yes | Yes |
| Simple audio sample playback | No | Yes |
| Active devices at a time | 1 | Multiple |
| Presets per device | Up to 2 | Unlimited |
| Mappings per preset | Up to 6 | Unlimited |

## Notes

- These limits apply to version `1.2.0`.
- MIDI Thru requires a virtual MIDI port.
- Download and purchase details are maintained on the [official download page](https://crowtherian.gumroad.com/l/ddscqt).
