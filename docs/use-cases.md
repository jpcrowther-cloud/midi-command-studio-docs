# Supported Use Cases

MIDI Command Studio is intended for Windows workflows where physical MIDI controls are useful for repeated actions, volume control, and app-specific shortcuts.

## Streaming And Content Creation

- Set up an OBS MIDI controller workflow for scene changes, mute actions, recording controls, or live production shortcuts
- Use pads or buttons for soundboard actions
- Build app-focused controls for streaming, playback, chat, browser, and recording tools

## Video Editing

- Use MIDI shortcuts for DaVinci Resolve or similar editing software
- Assign pads, buttons, encoders, or faders to repeated editing actions
- Build separate presets for editing, review, audio, and export workflows

## Audio And Volume Control

- Control Windows volume with a MIDI controller
- Create MIDI app volume control with faders or knobs
- Use system volume control for monitor, speaker, or headphone workflows
- Assign mute, utility, or preset actions to physical controls where supported

## Productivity And Power Users

- Launch applications or scripts through mapped shortcuts or macros
- Build global mappings for desktop-wide commands
- Build app-focused mappings for specific programs
- Reuse existing MIDI gear as a compact desktop control surface

## Music Hardware Outside A DAW

MIDI Command Studio is not a DAW plugin. It is for using MIDI hardware outside music production software as a Windows control surface, MIDI macro tool, or Stream Deck alternative using MIDI hardware.
