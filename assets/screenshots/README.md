# Screenshots

Store public MIDI Command Studio screenshots here.

Recommended files:

- `main-window.png`: main application window
- `shortcut-palette.png`: shortcut palette
- `preset-switching-settings.png`: preset switching settings
- `device-feedback-settings.png`: device feedback settings
- `edit-mapping-dialog.png`: mapping editor
- `macro-editor-dialog.png`: macro editor
- `general-settings-tab.png`: general settings

Avoid screenshots that show private license details, personal file paths, unpublished features, or unrelated applications unless they are required to explain a documented workflow.
