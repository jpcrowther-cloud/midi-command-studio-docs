# Contributing To Documentation

This repository accepts public documentation improvements for MIDI Command Studio.

The application itself is closed-source. Do not submit or request application source code in this repository.

## Useful Contributions

- Documentation corrections
- Broken link fixes
- Screenshot or GIF updates
- Release-note corrections
- Verified external resources such as Softpedia, KVR, Rekkerd, or YouTube links
- Tested controller notes with exact model, app version, and Windows version
- Troubleshooting details that can be reproduced

## Before Adding Claims

Only add claims that can be verified. Avoid untested compatibility statements, user counts, performance claims, or review quotes without a real source.

For controller notes, include:

- MIDI Command Studio version
- Windows version
- Controller make and model
- Connection type
- Tested controls and MIDI message types
- Feedback behavior if relevant

## Issue Templates

Use the provided issue templates for:

- Documentation issues
- Application issue reports, if public issue tracking is enabled
- External resource suggestions

Private support, licensing, purchase, or account questions should use the official support route listed in [SUPPORT.md](SUPPORT.md).
